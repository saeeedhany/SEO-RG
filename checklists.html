SEO Checklists

Practical, field-tested checklists for every major SEO operation. Use them before you publish, before you migrate, before you launch a campaign. Each one is a distillation of the relevant handbook — no fluff, just the steps.

5 checklists · Pre-publish · Technical Audit · Migration · Local Setup · Link Campaign

Checklist 01

Pre-Publish Checklist

Run this before publishing any new page or article. Every item is a common failure point — missing even one can meaningfully reduce ranking potential or CTR.

Keyword & Intent

  • Target keyword confirmed — one primary keyword per URL
  • Search intent matched — informational / commercial / transactional / navigational
  • SERP studied — top 5 results reviewed for format, depth, and angle
  • Content gap identified — page covers what top results miss
  • Semantic keywords included naturally — related terms, synonyms, entities

On-Page Elements

  • Title tag written — under 60 characters, target keyword front-loaded
  • Meta description written — under 160 characters, includes keyword, has a clear value proposition
  • H1 present — one per page, matches or is close to title tag
  • H2–H4 hierarchy logical — no heading levels skipped
  • URL slug short and keyword-containing — no stop words, no dates unless necessary
  • Canonical tag set — pointing to the preferred URL
  • Open Graph tags set — title, description, image (1200×630px minimum)

Content Quality

  • Content is original — no copied or paraphrased passages from ranking pages
  • Author bio included — with credentials relevant to the topic
  • External sources cited — authoritative, recent, linked correctly
  • Images have descriptive alt text — includes keyword where relevant and natural
  • Content reviewed for factual accuracy — statistics current and sourced
  • Publish date visible — and a "last updated" date policy in place

Technical

  • Page is not blocked in robots.txt or by noindex tag
  • At least 2–3 internal links pointing to this new page from existing content
  • New page links to 2–5 relevant internal pages
  • Sitemap updated or auto-regenerated
  • Page speed tested in PageSpeed Insights — Core Web Vitals passing
  • Mobile rendering tested — no layout issues on small screens
  • Structured data added if applicable — Article, FAQ, HowTo, Product, Review
  • Rich result eligibility tested in Google Rich Results Test

Post-Publish

  • URL submitted to Google Search Console for indexing
  • Ranking tracked in Ahrefs / Semrush within 48 hours
  • Performance review scheduled — 30 days, 90 days

Checklist 02

Technical SEO Audit Checklist

Run this quarterly, after any major site change, or when organic traffic drops unexpectedly. Tools needed: Google Search Console, Screaming Frog (or Ahrefs Site Audit), PageSpeed Insights.

Crawlability

  • robots.txt reviewed — no critical pages or folders accidentally blocked
  • XML sitemap present, valid, and submitted to Search Console
  • Sitemap contains only indexable, canonical URLs (no noindex, no redirects)
  • Crawl errors reviewed in Search Console — 4xx and 5xx errors resolved
  • Internal links audited — no broken internal links
  • Redirect chains identified and collapsed to single hops
  • Orphan pages identified — every important page reachable via internal links

Indexation

  • Coverage report reviewed in Search Console — all exclusions understood
  • Duplicate content identified — parameter URLs, trailing slashes, www vs non-www
  • Canonical tags correct — self-referencing canonicals on all key pages
  • Pagination handled correctly — rel="next/prev" deprecated; ensure first page is self-canonical
  • Hreflang tags correct if serving multiple languages or regions
  • Thin content pages identified — consolidated, expanded, or noindexed

Page Speed & Core Web Vitals

  • LCP under 2.5s on mobile — largest element identified and optimised
  • INP under 200ms — no blocking JavaScript on critical interaction paths
  • CLS under 0.1 — no layout shifts from images without dimensions, fonts, or ads
  • Images served in WebP or AVIF format, with width/height attributes set
  • Server response time (TTFB) under 600ms
  • Render-blocking resources minimised — CSS inlined for critical, JS deferred

On-Page Technical

  • Every page has a unique title tag — no duplicates across the site
  • Every page has a unique meta description
  • Every page has exactly one H1
  • All images have non-empty alt attributes
  • Structured data validated — no errors in Rich Results Test
  • HTTPS across entire site — no mixed content warnings
  • Mobile usability — no touch targets too small, no viewport issues

Checklist 03

Site Migration Checklist

Site migrations are the highest-risk SEO operation. A poorly executed migration can destroy years of accumulated authority in days. Run this before, during, and after any domain change, redesign, or CMS switch.

Pre-Migration

  • Full crawl of current site — export all URLs, titles, meta, H1, and inbound link counts
  • Current rankings exported — snapshot of all tracked keywords and their positions
  • Top traffic pages identified from GA4 — these are your highest-priority URLs to protect
  • Redirect map created — every old URL mapped to its new equivalent (1:1 where possible)
  • Redirect map reviewed — no chains, no loops, no missing entries for top pages
  • New site crawled in staging — validate all new URLs and on-page elements before launch

Migration Day

  • Redirects deployed and tested — spot-check 20+ critical URLs manually
  • New sitemap submitted immediately in Search Console
  • Search Console change of address tool used (domain migrations only)
  • Robots.txt on new site confirmed — not blocking Googlebot
  • Analytics verified — GA4 firing correctly on new site
  • Old site not fully taken down for minimum 6 months — redirects must remain active

Post-Migration (30–90 days)

  • Coverage report monitored daily for first 2 weeks — watch for unexpected exclusions
  • Rankings monitored daily — expect some fluctuation; sustained drops need investigation
  • Crawl errors reviewed weekly — fix any 404s appearing from broken redirects
  • Backlinks on old domain checked — high-value links updated to point directly to new URLs
  • Internal links updated — no internal links still pointing to old URLs through redirects

Checklist 04

Local SEO Setup Checklist

For any business with a physical location or service area. Run once at launch, then use as a quarterly review framework.

Google Business Profile

  • GBP claimed and verified — via postcard, phone, or video
  • Business name exactly matches real-world signage — no keyword stuffing
  • Primary category selected — the most specific category available
  • Secondary categories added — up to 9 additional relevant categories
  • Business description written — 750 characters max, includes primary keyword naturally
  • Opening hours accurate — including special hours for holidays
  • Phone number correct — tracked number acceptable, must be local format
  • Website URL added — pointing to most relevant landing page
  • Services / products added — with descriptions and prices where applicable
  • Photos uploaded — exterior, interior, team, products (minimum 10, ideally 20+)
  • GBP posts scheduled — weekly updates, offers, events
  • Q&A section populated — answer the most common questions proactively

NAP Consistency

  • NAP (Name, Address, Phone) defined — exact format decided and documented
  • NAP on website matches GBP exactly — including suite numbers, punctuation
  • Top 10 local directories checked — Yelp, Apple Maps, Bing Places, TripAdvisor, Facebook
  • Industry-specific directories added — legal, medical, hospitality directories as relevant
  • Schema LocalBusiness markup added to website — with matching NAP

Reviews

  • Review request process established — email or SMS follow-up sequence
  • Direct GBP review link created and tested — share with customers
  • All existing reviews responded to — positive and negative
  • Review monitoring set up — Google Alerts or tool notification for new reviews

Checklist 05

Link Building Campaign Checklist

Before launching any outreach campaign or link building initiative. Prevents common mistakes that waste effort or damage the link profile.

Foundation

  • Target pages identified — which specific URLs on your site need more authority?
  • Competitor backlink gap analysed — which sites link to competitors but not you?
  • Current link profile audited — toxic links identified, disavow file reviewed
  • Link-worthy asset created — what will make sites want to link?
  • Target prospect list built — minimum DR 40, topically relevant, real traffic

Outreach

  • Email template personalised — references specific content on their site
  • Clear value proposition — why should they link? What's in it for their readers?
  • From address matches domain — no generic Gmail addresses
  • Follow-up sequence limited to 2 emails maximum — one initial, one follow-up
  • CRM or spreadsheet tracking all outreach — prospect, status, date, response

Quality Control

  • All acquired links checked — contextual placement, no site-wide footer links
  • Anchor text varied — no more than 20% exact-match keyword anchors
  • No paid links without nofollow or sponsored attributes — Google guidelines compliance
  • New links logged in Ahrefs / Semrush — DR, traffic, and anchor text recorded
  • 30-day ranking movement reviewed — correlate link acquisition with position changes
